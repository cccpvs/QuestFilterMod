# Quest Filter Mod

Мод для измения квестов и привязки к торговцу. Удаление квестов определенных типов.
Случайные квесты по количеству и локациям.


### config.json
* "enabled" - Включение и отключение мода.
* "targetTraderId" - Ид Торговца для переноса всех квестов на данного торговца. Если не указан квест останеться по стандарту у торговца.
* "ExcludeArenaQuests" - Если включено, убрать квесты назначенные в арене.
* "debug" - Дебаг сообщения консоли.
* "questTypes" - Категории квестов для активации и переноса если указан targetTraderId. Исползуеться вместе с "removeOtherQuests" для удаление других квестов.
* "removeOtherQuests" - Удаление всех квестов которых нет в "questTypes".
* "removeStartConditions" - Удаляем все условия начала квеста. Удаляеться все, уровень, прошлый квест и прочее.
* "RemoveFinishConditionTypes" - Удаление условий для выполнения квеста. Например Elimination убироает условия квеста на убийство целей.

	#### GenerateRandomQuests

	Генерация новых случайных простых квестов. По локациям и по предметам. Только простая реализация.
	Для настройки есть отдельный файл настроек QuestConfig.json.
	Квесты созданные случайно привязываються к торговцу который указан в настройках QuestConfig.json

    "enable" - Включение генератора случайных квестов.
    "count" - Количество случайныз квестов.
    "onlyRandom" - Если Истина только случайные квесты без стандартных. Стандартные будет удалены.

	Вообще генератор случайных квестом слишком ужат для работы. Создан для теста.
	Если Количество "count" равно = 0 тогда система не создаст случайных квестов и будут только стандартные. 

	#### RandomQuests

	Случайные квесты на основе стандартных или со стороны модовых.
	Настройка для случайных квестов, общего списка или по локациям. Зависит от "targetTraderId" и "questTypes"

	* "count" - Общее количество случайных квестов
	* "location" - привязка по локации.
	* "factory4_day" - если указано 3, тогда только три квеста на данной локации.

	Если "count" = 5, а другие локации ровны 0, кроме локации bigmap = 3, система подберет 3 квета на bigmap остальные случайные 2 по другим локациям.

	#### removeStartConditions

	Удаление всех условий получения квеста. Теперь необязательно иметь последовательность в других квестах и условиях его получения. 
	Удаляються все условия квеста, уровень, квест, последовательность.

### questTypes

Категории квестов для оработчки и фильтрации. Список возможных категорий.

	[ "Completion", "Discover", "Elimination", "Experience", "Exploration", "Loyalty", "Merchant", "Multi", "PickUp", "Skill", "Standing", "WeaponAssembly" ]


### RemoveFinishConditionTypes
  
Удаление условий выполнения квеста. Квесты которые не будут иметь условий будут удалены.
Например условие "Elimination" - удалить в квесте условия убиств для выполения.

	["Completion","Elimination","Experience","Exploration","PickUp"]

### Общий статус мода
	
Мод был создан для личной потребности в использовани вместе с модом "Vagabond".
Так как некоторые квесты не очень сочетались с таким типом игры.
Тестирование на Vagabond ~ 0.7.
Тестирование с модами на квесты проводились - Lotus 1.7.2 - https://forge.sp-tarkov.com/mod/1232/lotus
Можно использовать на стандартной версии игры без модификаций и измений.

### Проблемы

Вообще часть квестов может не работат как нужно. У них есть зависимости от других квестов или уровня торговца и прочего.
Иногда удаление условий может сломать квест и его порядок в системе.
