# Quest Filter Mod [com.cccpvs.QuestFilterMod]

Мод для измения квестов и привязки к торговцу. Удаление квестов определенных типов.
Случайные квесты по количеству и локациям.


### Config.json
* Enabled - Включение и отключение мода.
* TargetTraderId - Ид Торговца для переноса всех квестов на данного торговца. 
	Если не указан квест останеться базового у торговца.
* ExcludeArenaQuests - Если включено, убрать квесты назначенные для арены.
* Debug - Дебаг сообщения консоли. Включение подробных сообщений для анализа.
* QuestTypes - Категории квестов для активации и переноса если указан targetTraderId. Используеться вместе с "RemoveOtherQuests" для удаление других квестов.
* RemoveQuests - Удаление всех квестов которых нет в "questTypes". Кроме случайных квестов.
* RemoveStartConditionsQuest - Удаляем все условия начала квеста. Удаляеться все, уровень, прошлый квест и прочее.
* RemoveFinishConditionTypes - Удаление условий для выполнения квеста. Например Elimination убирает условия квеста на убийство целей. 
	Так же удаляет условия из случайных квестов.
* RemoveRepeatableQuests - Удаление старндартных временных квестов из базы.


	#### GenerateRandomQuests

	Генерация новых случайных простых квестов. По локациям и по предметам. Только простая реализация.
	Для настройки есть отдельный файл настроек - RandomQuestConfig.json.
	Квесты созданные случайно привязываються к торговцу который указан в настройках - RandomQuestConfig.json

    enable - Включение генератора случайных квестов.
    count - Количество случайных квестов.
    
	Полный список параметров смотреть в RandomQuestConfig.json

	#### RandomQuests

	Создание случайного списка из стандартных или модовых квестов. Количество и привязке к локации.
	Не влияет на изменение случайно созданных квестов в "GenerateRandomQuests"

	Зависит от "TargetTraderId" и "QuestTypes"

	* count - Общее количество случайных квестов
	* location - привязка по локации.
	
	Если "count" = 5, а другие локации ровны 0, кроме локации bigmap = 3, система подберет 3 квета на bigmap остальные случайные 2 по другим локациям.

	#### RemoveStartConditions

	Удаление всех условий получения квеста. Теперь необязательно иметь последовательность в других квестах и условиях его получения. 
	Удаляються все условия квеста, уровень, квест, последовательность.

### QuestTypes

Категории квестов для оработчки и фильтрации. Список возможных категорий.
Для параметра настроек "QuestTypes"

	[ "Completion", "Discover", "Elimination", "Experience", "Exploration", "Loyalty", "Merchant", "Multi", "PickUp", "Skill", "Standing", "WeaponAssembly" ]


### RemoveFinishConditionTypes
  
Удаление условий выполнения квеста. Квесты которые не будут иметь условий будут удалены.
Например условие "Elimination" - удалить в квесте условия убиств для выполения.

	["Completion","Elimination","Experience","Exploration","PickUp"]

### RandomQuestConfig.json

Конфиг для настройки случано-генирированных квестов. Настройка Локаций, Наград, Условий.

### Общий статус мода
	
Мод был создан для личной потребности в использовани вместе с модом "Vagabond".
Так как некоторые квесты не очень сочетались с таким типом игры.

Тестирование на Vagabond ~ 0.7.

Тестирование с модами на квесты проводились - Lotus 1.7.2 - https://forge.sp-tarkov.com/mod/1232/lotus

Можно использовать на стандартной версии игры без модификаций и измений.

### Проблемы

Локализация только EN/RU с другими могут быть проблемы. 
Вообще часть квестов может не работат как нужно. У них есть зависимости от других квестов или уровня торговца и прочего.
Иногда удаление условий может сломать квест и его порядок в системе.
Случайные квесты могут содержать ряд ошибок и генерацию сломанную. Это дорабатываеться.
При удалении всех временных квестов иногда ошибка при загрузке клиента.
