# Quest Filter Mod

	Мод для измения квестов и привязки к торговцу. Удаление квестов определенных типов.


### config.json
	* "enabled" - Включение и отключение мода.
	* "targetTraderId" - Ид Торговца для переноса всех квестов на данного торговца. Если не указан квест останеться по стандарту у торговца.
	* "ExcludeArenaQuests" - Если включено, убрать квесты назначенные в арене.
	* "debug" - Дебаг сообщения консоли.
	* "questTypes" - Категории квестов для активации и переноса если указан targetTraderId. Исползуеться вместе с "removeOtherQuests" для удаление других квестов.
	* "removeOtherQuests" - Удаление типов квестов которых нет в "questTypes".
	* "removeStartConditions" - Удаляем все условия начала квеста. Удаляеться все уровень, прошлый квест и прочее.

	## RandomQuests

	Настройка для случайных квестов, общего списка или по локациям. Зависит от "targetTraderId" и "questTypes"

	* "count" - Общее количество случайных квестов
	* "location" - привязка по локации.
	* "factory4_day" - если указано 3, тогда только три квеста на данной локации.

	Если "count" = 5, а другие локации ровны 0, кроме локации bigmap = 3, система подберет 3 квета на bigmap остальные случайные 2 по другим локациям.


### Общий статус мода
	
	Мод был создан для личной потребности в использовани вместе с модом "Vagabond".
	Так как некоторые квесты не очень сочетались с таким типом игры.
	Тестирование на Vagabond ~ 0.7.
	Тестирование со сторонними квестами не проводилось.

	Вообще часть квестов может не работат как нужно. У них есть зависимости от других квестов или уровня торговца и прочего.
