# Quest Filter Mod [com.cccpvs.QuestFilterMod]

Мод для изменения условий, сортировки и привязки к торговцу. 
Сортировка по типу квеста, удаление условий начала.
Генератор случайных квестов, награды, условия.

---
> [!NOTE]
> Помните что фильтры и сортировка квестов работает лишь на одну сессию запуска SPT.
> 
> Фильтры, сортировка, случайность не сохраняеться в файлах.
> 
> Мы рассмотрим возможность сохранять новый процесс квестов по новым цепочкам по возможности в будущем.
> 
> Стандартные квесты работают по принципу и подаче как есть. Если к ним не будут примены фильтры.

---

## Config.json
---

* Enabled - Включение и отключение мода.

* TargetTraderIds - Ид списка Торгорцев для случайного переноса по списку. 
	* Пустое значение не меняет кто выдает квест. Он останеться у базового торговца.
	* Например если указать **[ "579dc571d53a0658a154fbec", "54cb57776803fa99248b456e" ]** то квесты будут случайно распределены по этому списку торовцев.

> [!WARNING]
> Это настройка работает лишь со стандартными или модовомы квестами. Случайно созданные квесты настроиваються отдельно.

> [!TIP]
> Пустое значение = **[]** пропускает фильтрацию, квест останеться у своего торговца.

* ExcludeArenaQuests - Если включено, убирает все квесты созданные для **Арены**

* Debug  - Дебаг сообщения консоли. Включение подробных сообщений для анализа.

* CleanDroppedItems - Удаляем из профиля игрока брошенные предметы. Влияет на квесты с предметами. 
	* Отключенное состояние будет сразу выполнять условия похожих квестов на точках и локациях при повторном посещении.
	* **Помните!** Квесты на закладку предмета сохраняют предмет и точку в профиль. Поэтому нужно включать этот параметр если квесты будут похожы.

* QuestTypes - Категории квестов для активации и переноса если указан **targetTraderIds**. 
	* Используеться вместе с **"RemoveOtherQuests"** для удаление других квестов.
	* Для удаление всех квестов список **QuestTypes** должен быть пуст.
	* Если **QuestTypes** пуст, случайно подобранные квесты **RandomQuests** не сработают. Обязательно нужно указать тип квеста.

> [!WARNING]
> Если **QuestTypes** содержить хоть один тип квеста, параметр **"RemoveOtherQuests"** не сработает и остануться те квесты из типов **QuestTypes** 
	
* LinkedQuest - Цепочка квестов. Фильтр работает на все квесты, стандартные, случайные - возможно модовые.
	* В данном виде **RemoveStartConditionsQuest** не будет работать вместе с **LinkedQuest**
	
	* "Enable": false, - Включение и отключение цепочки квестов.
	* "StartQuest": [ 1, 5 ], - Количество квестов слечайное выдаваемые сначала.
	* "QuestFinish": [ 1, 3 ] - Количество квестов случайное после выполнения одного квеста.
	
	* Так как **LinkedQuest** создает список новый цепочки квестов, все начальные условия квестов будут удалены.
	* Это заменяет параметр **RemoveStartConditionsQuest** который просто удалял условия.
	
> [!WARNING]
> Внимание! Все квесты будут идити по очереди. Удаляет стартовые условия всех квестов. 

* RemoveStandartQuests - Удаление стандартых квестов, согласно фильтрации
	* Используйте для точной фильтрации квестов вместе с другими фильтрами.
	* Явно зависит для работы фильтра, сортировки.

> [!WARNING]
> Внимание! Очень важный параметр для использования фильтрации.

* ModifyBaseQuest - Модификатор базовых квестов
	* Настройка добавляет новые случайные условия задач для базовых квестов.
		* Enabled - Включение/отключение модификатора.
		* Type - Типы добавляемых задач (условий) - **аналогия** комбо-квес
		
			  [ "Exploration", "Delivery", "Beacon", "Kills", "Transfer" ]
		* CountCond - Количество условий для добавляения - от и до.
		
> [!WARNING]
> Данная настройка сильно влияет на загрузку мода в целом.

> [!TIP]
> Что награды, не изменяються от добавленных условий задач.
> 
> Чем больше условий, долше загрузка базы квестов.


* SkipQuest - Фильтр пропустит данные квесты по условиям, квеста остануться без изменений.
	* Traider - Список тоговцев для пропуска фильтра. Аналогия - **TargetTraderIds**
	* Types - Список типов квестов пропуска фильтра. Аналогия - **QuestTypes**

> [!TIP]
> Типы пропускаемых квестов **Types** ищите в **QuestTypes** и используйте те же параметры пропуска.
>
> Имейте понимания что **SkipQuest** пропустить любой фильтр для базового квеста или модового, даже удаление.

> [!WARNING]
> Пропуск работает вне зависимости других параметров фильтра как первый и начальный.
>
> Квесты из пропуска не будут удалены используя **RemoveStandartQuests**


* RemoveStartConditionsQuest - Удаляем все условия начала квеста. Удаляеться все, уровень, прошлый квест и прочее.
	* Не работает если активен **LinkedQuest**

* RemoveFinishConditionTypes - Удаление условий для выполнения квеста.
	* Например **Elimination** убирает условия квеста на убийство целей.
	
> [!TIP]
> Помните Что у квеста может быть одно условие и удаление условий сразу выполнить квест.


* RemoveRepeatableQuests - Удаление квестов которые выдаються на день, неделю.

* GenerateRandomQuests - Генерация новых случайных простых квестов. По локациям и по предметам. Только простая реализация.
	* Для настройки есть отдельный файл настроек - **RandomQuestConfig.json**.
	* Квесты созданные случайно привязываються к торговцу или списку торговцев который указан в настройках - **RandomQuestConfig.json**
	 
	* enable - включение/отключение создания случайных квестов.
	* count - Количество случайных квестов.
	 
	* Настройки и полный конфиг находиться отдельно - **RandomQuestConfig.json**


* RandomQuests
	* Создание случайного списка из стандартных или модовых квестов. Количество и привязке к локации.
	
	* count - Общее количество случайных квестов со всех локаций.
	* location - привязка по локации.
	  
	* Фильтрация будет премена только к количеству квестов, если использовано в **count** или **location**
	
> [!WARNING]
> Это настройка берет случайные квесты, которые могу не попасть в список если не удалить начальные условия **RemoveStartConditionsQuest**
>
> Начальные квесты могу и не появиться, если использовать малое количество.
>
> Для очистки других квестов используйте - **RemoveStandartQuests** - иначе эффект сортировки будет другой.

  
* Не влияет на изменение случайно созданных квестов в **"GenerateRandomQuests"**
* Зависит от **"TargetTraderIds"** и **"QuestTypes"** и **RemoveStartConditionsQuest**
	  
* Если "count" = 5, а другие локации ровны 0, кроме локации Bigmap = 3, система подберет 3 квета на bigmap остальные случайные 2 по другим локациям.
* Если "count" = 5, а все локации указаны по 0, тогда система создать 5 случайных квестов по всем локациям.
* Если **"count" = 0** , а например **Factory4Day = 5** квесты будут подобраны только по этой локации.

> [!TIP]
> Это работает лишь со стандартными квестами и квестами других модов, случайно созданные квесты настраиваються отдельно.
>
> Если **QuestTypes** пустой и включено **RemoveStandartQuests** - не будут подобраны случайные стандартные квесты.
	
* Система просто подбирает случайные стандартные или модовые квесты, со всего списка.
* К данным квестам будет примены фильтры только согласно от **TargetTraderIds** и **ModifyBaseQuest**

## Подробнее

#### RemoveStartConditions
* Удаление всех условий получения квеста. Теперь необязательно иметь последовательность в других квестах и условиях его получения. 
* Удаляються все условия квеста, уровень, квест, последовательность.


#### TargetTraderIds
* Список торговцев которым будут назначены стандартные квесты или квесты из других модов. Не распростроняеться на **GenerateRandomQuests**.
* Если список пуст - квесты остануться у своих торговцев.

> [!TIP]
> Используеться в **TargetTraderIds** и **SkipQuest/Traider**
>
> В **SkipQuest/Traider** используеться как список пропуска фильтра торговцев.
>

	  [ "54cb50c76803fa8b248b4571", "54cb57776803fa99248b456e", "579dc571d53a0658a154fbec", "58330581ace78e27b8b10cee", "5935c25fb3acc3127c3d8cd9", "5a7c2eca46aef81a7ca2145d", "5ac3b934156ae10c4430e83c", "5c0647fdd443bc2504c2d371", "6617beeaa9cfa777ca915b7c" ]

### QuestTypes
* Список типов квестов для фильтрации списка.
* Используйте для сортировки квестов по типу, задаче.
* Если список пуст, фильтр уберет все типы квестов.
* Используйте вместе с **RandomQuests** и количеством случайных квестов.


> [!WARNING]
> Внимание! Для удаления других квестов используйте **RemoveStandartQuests**, иначе фильтр не сработает.


	  [ "Completion", "Discover", "Elimination", "Experience", "Exploration", "Loyalty", "Merchant", "Multi", "PickUp", "Skill", "Standing", "WeaponAssembly" ]

### RemoveFinishConditionTypes
* Удаление условий завершения квеста. Пустое значение отключает удаление условий.
  
> [!WARNING]
> Есть квесты которые могут быть с одним условием и будут сразу выполнены.
>
> Некоторые условия содержать в себе привязаныне условия. Они будут тоже удалены.
>
> Список возможных вариантов завершения условий квеста:

	  ["FindItem","GlobalVariableValue","HandoverItem","HideoutArea","LeaveItemAtLocation","PlaceBeacon","Quest","SellItemToTrader","Skill","TraderLoyalty","TraderStanding","VisitPlace","WeaponAssembly","Completion","Discover","Elimination","Experience","Exploration"]

### RemoveStandartQuests
Данный параметр предназначен для удаление лишних квестов которые не прошли фильтрацию. Без использования - может быть частичная фильтрация квестов.
Используйте для полной фильтрации, удаления квестов которые не были изменены.

### ModifyBaseQuest
* Базовые квесты получать новые задачи и условия для выполнения.
* Можно использовать вместе с **RemoveFinishConditionTypes** чтоб очистить базовый квест и получить другие задачи.
* При большом количестве дополнительных условий, увеличивает время загрузки мода и его инициализацию.
* Используйте ограниченное количество квестов, для быстрой загрузки мода.

### RandomQuestConfig.json
* Конфиг для настройки случано-генирированных квестов. Настройка Локаций, Наград, Условий.
* Фильтр на распрастроняеться на случайные квесты.

## Общий статус мода
	
Мод был создан для личной потребности в использовани вместе с модом "Vagabond".

Так как некоторые квесты не очень сочетались с таким типом игры.

## Локализация

Мод имеет локализацию. Возможно добавление возможной локализации из списка доступных системой игры.

В папке Locales имеються файлы для изменение локализации квестов. Используйте префикс перевода - jp.json для рабочего перевода.

	"ch", "cz", "es-mx", "es", "fr", "ge", "hu", "it", "jp", "kr", "pl", "po", "ro", "sk", "tu"

## Проблемы

Локализация только EN/RU, другие локализации ссылаються на EN.

Для создания Локализации можно создать свой файл локализации от нужного языка.

Вообще часть квестов может не работат как нужно. У них есть зависимости от других квестов или уровня торговца и прочего.

Иногда удаление условий может сломать квест и его порядок в системе.

Случайные квесты пока что в разработке и могут быть с ошибками.
