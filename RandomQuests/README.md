### Случайное создание квеста.

QuestGeneration
Types - Типы квестов
	* Exploration - Квест на посещение точки на карте.
    * Delivery - Получение предмета и закладка на точке карты.

#### Locations
Список локаций для случайного выбора перебора.
* Id - Оригинальной карты (Обязательно).
* Targets - Цель квеста. Точка для посещения.

#### ExplorationQuests
Точки и локации для квестов типа Посетить точку. Список карт и их зоны посещения.

#### DeliveryQuest
Квест на получение предмета и закладку его на карте.

#### ItemCollectionQuests
Квест получить предмет на карте.

#### RewardItems
Список случайных наград для выдачи игроку.
* Name - Имя предмета.
* Count - Количество предметов на выдачу от 1 до 3.
* PriceRange - Стоимость подобранных предметов для подарка.
* Parents - Категории или родители выдаваемых предметов. 
	* Id - Категории, родителя.
	* Weight - Вес или шанс (0 - отключает).
	* Comment - Комментарий.

#### RewardTraderStanding
Репутация с торговцем после выполния квеста.
Значения от и до.

#### PlantingQuests
Настройки для типа квеста - Заложить предмер.
Список предметов для квеста указан по весу и ид.
Список точек закладки предметов береться из "ExplorationTargets"

#### DefaultQuest
Общие настройки квеста.

* ExperienceRewardRange - Настройки случайно награды опыта игроку за выполнения квеста. Минимальное и Максимальное значение. И шаг случайного значения.
