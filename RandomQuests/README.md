### Случайное создание квеста. 

Настройки генерации новых случайных квестов по условиям, локациям, наградам.

### QuestGeneration
Types - Типы квестов
	* Exploration - Квест на посещение точки на карте.
    * Delivery - Получение предмета и закладка на точке карты.
	* Kills - Квест на убийства.
	* Beacon - Квест пометить позицию или точку маркером.
	* Transfer - Квест доставить предмет из рейда.

#### AllowedLocations
Локации разрешенные для генерации случайного квеста. Отключение и включение локаций.
Два параметра - true - false


#### ExplorationQuests
Точки и локации для квестов типа Посетить точку. Список карт и их зоны посещения.
Список локаций и точки данных локаций.

#### DeliveryQuest
Квест на получение предмета и закладку его на карте.
	* PlantTime - Время на закладку предмета в секундах.
	* ItemPlant - ИД Предмета, выданные для выполнения квеста.
	* Locations - Список локаций для зон.

#### BeaconQuest
Квест на использования маяка для метки позиции или места.
	* PlantTime - Время на закладку предмета в секундах.
	* ItemPlant - ИД Предмета, для маяка. Внимание! не используйте другие предметы, они сломают игровую логику.
	* Locations - Список локаций для зон.

#### TransferQuest
Квест на передачу предмета торговцу из рейда. С настраиваемым количеством передаваемых предметов.
Помните! Локации не работают на данный тип квеста.

* ItemCount - Количество передаваемых предметов за раз. От и До. Например от 1 до 5.
* Condition - Количество условий от и до. Случайное количество условий передаваемых предметов в одном квесте.
* ItemIds - Список предметов передаваемых торговцу. 

#### KillQuest
Квесты на убийства разных типов игроков.
Массив значений и вариантов.

* MinKills - Минимальное количество убийств.
* MaxKills - Максимальное количество убийств.
* Target - Массив целей для квеста.
	Чем больше вариантов, больше возможных квестов.
	Помните! Что варианты могут быть зависимы от типов целей.
	Возможные варинаты для Target = Any - Savage - AnyPmc - Usec - Bear

#### RewardMoney
* Enabled - Включение награды денег за выполнение.
* Tpl - Ид валюты при награде.
* Min - Минимальная сумма награды.
* Max - Максимальная сумма награды.
* Step - Шаг слушайной суммы. Если 500 то 10500, 120500.

#### RewardItems
Список случайных наград для выдачи игроку за выполненый квест.

* Count - Количество предметов на выдачу от 1 до 10.
	(Слишком большое число до может быть ограничего интерфейсом игры)
* PriceRange - Стоимость подобранных предметов для подарка.
	(Стоимость выданных предметов на основании ценовых парамтров в **prices.json**)
* Parents - Категории или родители выдаваемых предметов.
	(В некоторых категориях есть предметы которые могут конфликтовать)
	* Id - Категории, родителя.
	* Weight - Вес или шанс (0 - отключает).
	* Comment - Комментарий.

#### DefaultQuest
Общие настройки квеста.
* Image - Фотография созданного случайного квеста.
* ExperienceRewardRange - опыт за выполненый квест.
	* Min - Минимально опыта
	* Max - Максимально опыта
	* Step - Шаг опыта между минимальным и максимальным.

#### RewardTraderStanding
Репутация с торговцем после выполния квеста.
* Enabled - Включение награды отношения с торговцем.
* Min - Минимальная репутация за квест.
* Max - Максимальная репутация за квест.

#### TraderIds
