### Случайное создание квеста.

#### Locations
Список локаций для случайного выбора перебора.
* "Id" - Оригинальной карты (Обязательно).
* "Targets" - Цель квеста. Точка для посещения.

#### RewardItems
Список случайных наград для выдачи игроку.
* "Name" - Имя предмета.
* "Tpl" - ИД предмета для из базы предметов.
* "Count" - Количество предмета.

#### DefaultQuest
Общие настройки квеста.
