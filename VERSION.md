-----------------------------------------------------------------------------------

* Внесенные изменения на версию SPT 4.1.2.
* Небольшие правки кода.

### Версия 1.0.4
-----------------------------------------------------------------------------------
### Добавлено
* Пропуск фильтрации квестов по торговцу или по типу квесту. "SkipQuest"
	Система пропустить доступные квесты из фильтра и изменения.
-----------------------------------------------------------------------------------
### Исправлено. 
* Случайные условия для базовых квестов. Исправлена ошибка условий для одной сессии.
	Дополнительные условия для квестов могли сбрасываться от частичного прохождения.
-----------------------------------------------------------------------------------
### Изменено. 
* Квесты Посещение точки. Теперь явно можно указать условия к квесту выжить или транзит.
	Можно отключить условие выжить на локации для квеста.

* Квесты Убиства. Просеты оружия.
	Теперь при указании оружия выдаеться его собранная версия.
	Подробнее **RandomQuests.README**.

> [!CAUTION]
> Обновлен файл конфигурации **RandomQuestConfig.json**

### Версия 1.0.2
-----------------------------------------------------------------------------------
* Добавлено. Комбо-квест
	Генерация случайных комбо квестов - квест включает разные типы задач
	Настройка количества условий от/до, привязка к локации, типа квеста.
* Добавлено. Цепочка квестов.
	Все квесты, стандартные, случайные, теперь будут в случайной цепочке выполнения.
	Настройка случайного количества начальных квестов и цепочки выполненых квестов.
	После выполнения квеста может выдаться случайное количество квестов.
* Добавлено. Награда Скилл.
	На выполнение случайного квеста можно добавить награду скилла игроку.
	Настройка количества, скрытия, случайности, отключения.
-----------------------------------------------------------------------------------
* Исправлено. Работа **RemoveFinishConditionTypes**.
	Испралено удаление для завершения квестов.
	Обновлен список возможных условий окончания квеста.
	Смотрите **README.md**
-----------------------------------------------------------------------------------
* Изменено. **ExperienceRewardRange** теперь отдельно в настройках.
	Обновите **RandomQuestConfig.json**
* Изменено. Сгенерирование квесты. Скрытие наград при выполнение квеста.
	В параметрах наград теперь есть поле **Unknown** для скрытие наград за выполнеие квеста.
	Можно в квесте скрыт какую награду получить игрок после выполненения.


### Версия 1.0.1
-----------------------------------------------------------------------------------
* Новое. Добавлен тип квеста - Маяк.
	Данный квеста похож на квест закладки предмета. Но для выполнения нужен маяк или генератор помех.
	Предмет выдаеться при старте квеста.
	Настройка через **RandomQuestConfig.json**. Таймер выполнения. Зоны размещения
* Новое. Квест на передачу предметов из рейда.
	Квесты на поиск и прередачу предметов из рейда. С настройкой количества предметов и условий.
	Настройка предметов для поиска. Доступно на всех локациях.
* Новое. Локализация - Отдельно.
	Все локализации можно изменить или добавить по удобству.
	Базово добавлено только EN,RU
	Файлы локализации лежат в папке **Locales** имеют формат **.json**
* Новое. Квест - Убийства - Цели.
	Добавлен массив целей для большей генерации квестов на локации.
	Настройки целей используйте в **RandomQuestConfig.json**.
-----------------------------------------------------------------------------------
* Обновление. Зоны для квестов.
	Добавлены новые локации для генерации квестовых зон.
	Требуеться обновить **RandomQuestConfig.json** на новую версию.
	Полноценно все точки квестов были не полностью проверены.
* Обновление. Квесты торговцев на переназначение.
	Теперь стандартные квесты могут быть распределены больше чем на 1 торговца.
	Пустое значение [] пропустит перераспределение.
	Обновите **Config.json**
-----------------------------------------------------------------------------------
* Изменено. Фильтрация квестов
	Убрана фильтрация случайных квестов вместе со стандартными.
* Изменено. Квест - Доставка и Маяк.
	Убраны дубликаты позиций возможных генераций квеста.
* Изменено. Квест посещение точки.
	Теперь условия посетить зону и выйти с локации будет выполенено в одной сессии.
-----------------------------------------------------------------------------------
* Исправлено. Фильтр стандартных по локациям.
	Исправлен код сортировки квестов по случайному отбору по локациям.
	Немного изменена логика сортировки по локациям. Смотреть в **README.md**
